# Artive

Artive — the art of forgotten things. For the half-baked, half-written, half-whatever. Share your scraps, steal a spark, and build on the beautiful mess.

## Getting Started

### Prerequisites

- Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Technologies

This project is built with:

- Vite
- TypeScript
- React
- React Router
- shadcn-ui
- Tailwind CSS
